# 相亲市场定位测评

一个相亲定位测评 H5 + 私域引流 + 后台管理系统。用户答 9 组题，得到市值分、评级、双画像（理想型 / 底线型），报告页展示二维码引流加微信；后台可导出全部用户填写数据。

## 技术栈
- Next.js 15（App Router）+ TypeScript
- SQLite + Prisma（数据落库，可导出）
- Docker Compose 部署，容器 443 端口

---

## 一、本地开发

```bash
npm install
npx prisma db push        # 建库
npm run dev               # http://localhost:3000
```

## 二、构建 Docker 镜像（amd64，用于 Linux 云服务器）

```bash
# 一键构建 + 导出镜像包 + 打部署压缩包
bash build-image.sh
```

产物在 `dist/`：
- `xiangqin-image.tar`   —— Docker 镜像包
- `docker-compose.yml`   —— 编排文件
- `deploy.sh`            —— 一键部署脚本

## 三、服务器部署

把 `dist/` 里三个文件传到服务器同一目录，执行：

```bash
sudo bash deploy.sh
```

脚本会：载入镜像 → 建 `data/`（数据库）和 `public/`（上传文件）挂载目录 → 生成随机密钥 → 启动服务。

- 访问：`https://你的域名`
- 后台：`https://你的域名/admin`
- 默认用户测评密码：`6688`
- 默认后台管理密码：`admin8888`

> ⚠ 部署后请立即登录 /admin 修改这两个密码。
> 容器只监听 HTTP，HTTPS 证书在服务器的 Nginx / 宝塔 / Cloudflare 反代层配置。

## 四、数据持久化

- 数据库：`./data/prod.db`
- 上传文件（二维码）：`./public/uploads/`

两者都是外部挂载卷，**更新镜像重新部署不会清空**。

## 五、后台功能（/admin）

1. **导出数据** —— 一键导出全部用户的报告编号、微信号、想解决的问题、全部答题内容、九维分与总分（CSV，Excel 可直接打开），含提交时间与 IP。
2. **改密码** —— 分别修改「用户测评密码」和「后台管理密码」。
3. **换二维码** —— 上传替换报告页二维码。
4. **切引流文案** —— 两套引流文案任选其一（A 完整咨询 / B 资源包诱饵）。
5. **二维码显隐开关** —— 一键控制报告页是否展示二维码 + 引导语。关掉后报告页只出纯测评结果。
6. **最后一题模式** —— 问卷最后一步引导留微信号，可设「选填」（不填也能出报告）或「必填」（填了才能出报告）。

## 六、用户流程与身份对应

流程：封面输密码 → 选性别 → 9 组测评题 → **最后一步留微信号（选填/必填可配）** → 出报告。

- 每份报告有一个 **4 位报告编号**，展示在报告页二维码旁。
- 最后一题直接采集微信号，落入数据库，后台可导出。
- 若设为「选填」，用户不填也能出报告；加微信时可报编号，后台按编号对上明细。
